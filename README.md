# RetroGames By D.Lemonis – V5 QuizBall

## Νέα έκδοση
- Καθαρό πλαίσιο ονόματος εφαρμογής και ξεχωριστό κουτί Ρυθμίσεων.
- Ξεχωριστή ομάδα QuizBall.
- Κατηγορίες: PlayerID, Logo Quiz, Footballers, Ιστορία, Ερωτήσεις κοινού.
- Μαζική προσθήκη και επεξεργασία φωτογραφιών.
- Προσθήκη, επεξεργασία και διαγραφή ερωτήσεων στις κατηγορίες κειμένου.

## Φωτογραφίες ZIP
- `assets/players` για PlayerID.
- `assets/teams` για Logo Quiz.
- Εκτέλεσε το `Ενημέρωση_Βιβλιοθήκης.bat` σε Windows ή το `.command` σε Mac πριν την ανάρτηση στο GitHub.

## Ερωτήσεις από Word ή Σημειώσεις
Βάλε αρχεία `.docx` ή `.txt` στους φακέλους:
- `questions/playerid`
- `questions/footballers`
- `questions/history`
- `questions/audience`

Μετά τρέξε `Ενημέρωση_Βιβλιοθήκης.bat` στα Windows ή `Ενημέρωση_Βιβλιοθήκης.command` σε Mac. Οι ερωτήσεις και οι εικόνες ανακατεύονται και δεν επαναλαμβάνονται μέχρι να ολοκληρωθεί όλη η κατηγορία.

## TOP 5 – κανόνας ασφαλείας
- Απαιτούνται 5 σωστές απαντήσεις για 3 πόντους.
- Το πρώτο λάθος λειτουργεί ως μαξιλαράκι και ο παίκτης συνεχίζει.
- Το δεύτερο λάθος χάνει την ερώτηση.
- Αν ο παίκτης έχει 4 σωστές και έχει ήδη κάνει 1 λάθος, μπορεί να σταματήσει για 1 πόντο ή να ρισκάρει μία τελευταία απάντηση για 3 πόντους.
