## Ανέβασμα στο GitHub Pages
1. Δημιούργησε νέο repository στο GitHub.
2. Ανέβασε όλα τα αρχεία του φακέλου.
3. Πήγαινε Settings → Pages.
4. Στο Source επίλεξε Deploy from a branch.
5. Επίλεξε branch main και φάκελο /(root).
6. Πάτησε Save.

Η εφαρμογή αποθηκεύει το σκορ τοπικά στη συσκευή.
