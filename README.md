# RetroGames By D.Lemonis

Η εφαρμογή περιλαμβάνει:
- Τρίλιζα
- Σκορ 4
- Κρεμάλα
- Κορώνα–Γράμματα
- Τροχό Challenges με επεξεργασία επιλογών
- Σημαίες και χώρες
- Καρτέλα Αθλητισμός
- Μάντεψε τον ποδοσφαιριστή
- Μάντεψε το λογότυπο ομάδας
- Προσθήκη δικών σου φωτογραφιών και ονομάτων

## Ανέβασμα στο GitHub Pages
1. Ανέβασε όλα τα αρχεία του φακέλου.
2. Settings → Pages.
3. Deploy from a branch.
4. main και /(root).


## Νέα έκδοση
- Μαζική επιλογή φωτογραφιών ποδοσφαιριστών και σημάτων ομάδων.
- Συμπλήρωση ονομάτων μετά την επιλογή των φωτογραφιών.
- Μεταγενέστερη αλλαγή ονόματος ή φωτογραφίας.
- Περισσότεροι έτοιμοι ποδοσφαιριστές και σύστημα χωρίς άμεσες επαναλήψεις.
- Η κατηγορία «Ομάδες» μετονομάστηκε σε «Σήματα ομάδων».
